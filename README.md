# مدربك الشخصي — الكود المصدري

تطبيق ويب (PWA) لبرنامج الجيم: التمارين، المكتبة (502 تمرين)، الأكل، التقدّم، المساعد الذكي (Gemini)، النوادي القريبة، و9 لغات.
ما يحتاج أي تثبيت أو build — افتح المجلد في VS Code وشغّله على طول.

## التشغيل في VS Code

1. افتح المجلد: **File ← Open Folder** واختار هذا المجلد.
2. VS Code بيقترح عليك إضافة **Live Server** (ritwickdey.LiveServer) — ثبّتها.
3. كلك يمين على `index.html` ← **Open with Live Server**.
4. يفتح لك على `http://127.0.0.1:5500` — أي تعديل تحفظه يتحدّث في المتصفح على طول.

> لا تفتح `index.html` بالضغط المزدوج (file://) — المتصفح يمنع تحميل الفيديوهات وخاصية بدون نت. استخدم Live Server.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | هيكل الصفحة: الأزرار، التبويبات، النوافذ |
| `style.css` | كل التصميم والألوان (الوضع الفاتح والداكن) |
| `app.js` | كل منطق التطبيق (الشرح تحت) |
| `i18n.js` | كل النصوص بالـ 9 لغات |
| `anatomy.js` | أسماء وأشكال العضلات |
| `bodies.js` | رسومات الجسم (كبير، لا تعدّل عليه) |
| `lib/library.js` | بيانات الـ 502 تمرين في المكتبة (الاسم، العضلات، الجولات…) |
| `lib/thumbs.js` · `lib/layers.js` | صور مصغّرة وطبقات العضلات للمكتبة |
| `lib/p0.mp4 … p100.mp4` | فيديوهات المكتبة مجمّعة في حزم (كل حزمة فيها 5 فيديوهات) |
| `videos/*.mp4` | فيديوهات تمارين البرنامج |
| `icons/` · `manifest.webmanifest` | أيقونة التطبيق واسمه لما تنزّله على الجوال |
| `sw.js` | يخلي التطبيق يشتغل بدون نت |

## أهم الأقسام في `app.js`

استخدم **Ctrl+F** وابحث عن الاسم:

- `var LANGS` — اللغات المتاحة. `function t(` — جلب النص المترجم.
- `var DAYS` / `buildDays` — أيام البرنامج وتمارينها.
- `function plan(` — الجولات والتكرار والراحة لكل مرحلة.
- `busyMap` / `altEx` — زر «الجهاز مشغول» والبدائل.
- `var FOODS` / `var MEALS` — الأكل والوجبات.
- `function renderStatus` — بطاقة «حالتك الشخصية».
- `var GYM` / `gymFind` / `gemPlaces` — النوادي القريبة (OpenStreetMap + خرائط Google).
- `var GEM` / `gemSample` — المساعد الذكي بـ Gemini.
- `function libList` / `libVideo` — المكتبة وفيديوهاتها.

## إضافة نص أو ترجمة

كل نص له مفتاح في `i18n.js`، مثلاً `gymBtn:"نوادي قريبة"`.
في `index.html` تستخدمه بـ `data-i18n="gymBtn"`، وفي `app.js` بـ `t("gymBtn")`.
لو ضفت مفتاح جديد، ضيفه على الأقل بالعربي والإنجليزي — اللغات الثانية ترجع للإنجليزي لو ناقص.

## بياناتك

كل تقدّمك ينحفظ في المتصفح (localStorage) باسم `KEY` في `app.js`.
**لا تغيّر قيمة `KEY`** وإلا يضيع تقدّمك المحفوظ. وقبل أي تعديل كبير سوّ نسخة احتياطية من داخل التطبيق (تبويب «تقدّمي» ← «نزّل نسخة احتياطية»).
مفتاح Gemini ينحفظ في `coach-gemini-key` وما يطلع من جهازك.

## النشر على GitHub Pages

المجلد كامل جاهز ينرفع زي ما هو:

1. افتح المستودع `ab2054356-star/coach` ← **Add file ← Upload files**.
2. اسحب الملفات اللي عدّلتها (مثلاً `app.js` و `style.css`) واضغط **Commit changes**.
3. بعد دقيقة الرابط يتحدّث: `https://ab2054356-star.github.io/coach/`

> مهم: الموقع الحالي على GitHub مرفوع كملف واحد مدموج. أول مرة ترفع هذا المجلد، ارفع كل الملفات (`index.html`، `style.css`، `app.js`، `i18n.js`، `anatomy.js`، `bodies.js`، `sw.js`، ومجلد `lib` كامل) عشان يمشي على الطريقة الجديدة.

لو غيّرت أسماء ملفات أو ضفت ملف جديد لازم للتطبيق، ضيفه في قائمة `CORE` داخل `sw.js` وغيّر `VERSION` (مثلاً إلى `"v2"`).
